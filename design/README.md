# ეტრატი

ეტრატი (ლათინურად **Etrati** — ასე წერია ფანჯრის სათაურში და მისასალმებელ ეკრანზე, `APP_NAME`) არის PDF რედაქტორი Windows-ისთვის — Acrobat-ის ჩამნაცვლებელი, ქართული ინტერფეისით, რომელიც მთლიანად კომპიუტერზე მუშაობს. ეს სისტემა აღწერს მის ვიზუალურ ენას: ფერებს, ტიპოგრაფიას, ზომებს, კომპონენტებს და ეკრანებს. აპი დაწერილია PySide6-ზე (Qt, Fusion სტილი); ტოკენები გადადის QPalette-სა და QSS-ში (იხ. სექცია „Qt იმპლემენტაცია“).

სახელი: **ეტრატი** — ძველი ხელნაწერების პერგამენტი. იქიდან მოდის ორი იდეა: თბილი, ქაღალდისფერი ნეიტრალები და ერთი ძლიერი ფერი — ლოგოს წითელი, როგორც ხელნაწერის საწყისი ასო. ასოები კი რბილი და მომრგვალებულია — ერთი შრიფტი, Noto Sans Georgian.

## პრინციპები

1. **დოკუმენტი მთავარია.** ინტერფეისი წყნარია: ნეიტრალური ზედაპირები, თხელი ხაზები, ჩრდილი მხოლოდ ქაღალდს, მენიუს და დიალოგს. ფერადი მხოლოდ ის, რასაც მომხმარებელი აკეთებს ან ირჩევს.
2. **წითელი ცოტაა.** `brand` გამოიყენება: primary ღილაკზე (ერთი ხედში), არჩეულ ხელსაწყოზე, აქტიური ჩანართის ხაზზე, მონიშნულ მინიატურაზე. არასდროს — დიდ ფონებზე ან დეკორაციად.
3. **ქართული ტექსტი პირველ რიგში.** ქართული სიტყვები გრძელია: ლეიბლები ველის ზემოთ, მენიუ ≥280px, ტექსტი არ იჭრება ღილაკზე. line-height ფართოა (13/20).
4. **უსაფრთხოება ჩანს.** შეუქცევადი მოქმედება (სამუდამო წაშლა, დაფარვა, ფარული მონაცემების წაშლა) ყოველთვის `danger` ფერით, აიკონით და ტექსტით, რაც დაიკარგება.
5. **ორი თემა.** „ქაღალდი“ (ნათელი, ნაგულისხმევი) და „ღამე“ (მუქი). PDF გვერდი (`paper`) ორივეში თეთრია.

## ტექსტის ტონი

- მოკლე, პირდაპირი, თქვენობით: „გახსენით PDF ფაილი ან ჩააგდეთ ამ ფანჯარაში“.
- ღილაკზე ზმნა/არსებითი: „შენახვა“, „გაერთიანება…“. „…“ ნიშნავს, რომ დიალოგი გაიხსნება.
- შეცდომა = რა მოხდა + რა არ შეცვლილა + რა ქნას: „ფაილი დისკზე შეიცვალა მას შემდეგ, რაც გახსენით. დახურეთ და თავიდან გახსენით.“
- ციტატისთვის ქართული ბრჭყალები „…“. ემოჯი, ძახილის ნიშანი, „უპს“ — არა.
- ერთეულები ქართულად: მმ, კბ, მბ, გვ.

## ფერი

ყველა ფერი სემანტიკური ტოკენია (`tokens.json`), ორი თემით.

- **ზედაპირები:** `surface-100` (ზოლები, დიალოგი) → `surface-200` (ჩაღრმავებული: ჩანართების ზოლი, გვერდითი პანელი, სტატუსი) → `surface-raised` (ველები, მენიუ, ბარათი). `canvas` — გვერდების უკან. `paper` — თავად გვერდი.
- **ტექსტი:** `ink` (ძირითადი), `ink-muted` (მეორადი, ≥4.7:1 ყველა ზედაპირზე), `ink-disabled` (მხოლოდ გათიშული).
- **ხაზები:** `line` — დეკორატიული გამყოფი; `line-strong` — კონტროლის საზღვარი (≥3:1).
- **ბრენდი:** `brand` #D02020 (ლოგოს ფერი) ფონად, მასზე `on-brand`. წითელი ტექსტი/აიკონი — `brand-text` (მუქ თემაში ღიაა, რომ იკითხებოდეს). არჩეულის ფონი — `brand-soft`.
- **სიგნალები:** `info`, `success`, `warning`, `danger` + თითოეულის `*-soft` ბანერის ფონისთვის. `danger` ბრენდის წითელზე მუქია და ყოველთვის აიკონით მოდის, ამიტომ ბრენდში არ ერევა.
- **ფოკუსი:** `focus` — ცისფერი 2px რგოლი. განზრახ არა წითელი.
- **გვერდზე ნიშნები:** `mark-highlight`, `mark-current`, `mark-selection`, `mark-edit`, `mark-field`, `mark-redact`, `mark-crop`, `ink-pen`, `ink-signature` — თემასთან არ იცვლება, რადგან თეთრ ქაღალდზე იხატება (კოდში ახლა `view.py`-ში მყარად წერია; იგივე მნიშვნელობებია).

კონტრასტი შემოწმებულია: ტექსტი ≥4.5:1 თავის ზედაპირზე ორივე თემაში, კონტროლის საზღვარი და ფოკუსი ≥3:1.

## ტიპოგრაფია

**ერთი შრიფტი ყველგან — Noto Sans Georgian.** მომრგვალებული, რბილი ქართული ასოები (იგივე, რაც dOoo-ში). Serif არ გამოიყენება.

- წონები: **400** — ტექსტი; **500** — ლეიბლი, caption; **600** — სათაური, ღილაკი, აქტიური ჩანართი. 700 არა — ასოები უხეშდება.
- აპში ჩაიტვირთოს `QFontDatabase.addApplicationFont`-ით (`furceli/assets/fonts/`: NotoSansGeorgian და ლათინურისთვის NotoSans, ორივე variable ან 400/500/600, OFL ლიცენზია); სარეზერვო Segoe UI → Sylfaen. ლათინური ასოებისთვის („ETRATI“, „PDF“, „Ctrl+S“) სტეკში მეორეა Noto Sans — თუ Georgian ფაილში რომელიმე ლათინური ასო აკლია, იმავე სტილით გამოჩნდება.
- **mono** — Cascadia Mono / Consolas: მხოლოდ კლავიშები, მასშტაბი, გვერდის ნომრები.
- შკალა: `display` 40/48 · `heading` 22/30 · `title` 15/22 · `body` 13/20 (ნაგულისხმევი) · `body-strong` · `small` 12/18 · `caption` 11/16 · `mono` 12/18.
- სახელი „ეტრატი“ ლოგოსთან — Noto Sans Georgian 600.

## ზომები და ფორმა

- 4px ბადე: `space-1` 4 … `space-7` 48.
- კუთხეები: `radius-xs` 4 (checkbox) · `radius-sm` 6 (ღილაკი, ველი, ჩანართი) · `radius-md` 8 (მენიუ, ბანერი) · `radius-lg` 12 (დიალოგი, ბარათი) · `radius-pill` (მასშტაბის ჩიპი, ფერის წრე). აპის აიკონი თავისთავად 20%-იანი მომრგვალებით.
- კონტროლი: `control` 32px, `control-sm` 24, `control-lg` 40; ტოლბარი 44, ჩანართი 36, სტატუსი 26, გვერდითი პანელი 248, მინიატურა 132.
- ჩრდილები: `shadow-page`, `shadow-menu`, `shadow-dialog` — სხვაგან ჩრდილი არა.
- მოძრაობა: მინიმალური. Hover/press მყისიერი; პანელების გახსნა ანიმაციის გარეშე (Qt-ში ისედაც). ჩატვირთვის ინდიკატორი მხოლოდ 400მწ-ზე გრძელი ოპერაციისთვის.

## აიკონები

აპი იყენებს **Segoe Fluent Icons** გლიფებს (Windows 10-ზე Segoe MDL2 Assets) — `glyph(code, color)` window.py-ში. წესები:

- ზომა: მენიუ/ღილაკი/სია `icon` 16px; მთავარი ტოლბარი `icon-tool` 20px; მეორე ტოლბარი 18px. ფერი QPalette WindowText-იდან (`ink`); არჩეულზე `brand-text`; გათიშულზე `ink-disabled`. ფერი უნდა მოდიოდეს პალიტრიდან, რომ მუქ თემაზე გადართვისას აიკონები თავიდან დაიხატოს.
- ტოლბარზე მხოლოდ აიკონი + tooltip (სახელი და კლავიში). მენიუში აიკონი არჩევითია, მაგრამ ტექსტი ერთ ხაზზე სწორდება.
- ამ სისტემის HTML მაგალითებში აიკონები დახატულია მარტივი ხაზოვანი SVG-ით (`Etrati.svg()`), მხოლოდ საჩვენებლად.

## ლოგო

`assets/Logos/etrati-mark.svg` — თეთრი ფოთოლი წითელ (`brand`) მომრგვალებულ კვადრატზე (ფურცელი/ფოთოლი — სიტყვათა თამაში). წესები: არ გადაღებო, არ დაატრიალო, ირგვლივ თავისუფალი ადგილი ≥ ნიშნის 1/4. ლოგოს გვერდით სახელი ეწერება Noto Sans Georgian 600-ით („ეტრატი“), ნიშნის სიმაღლის ~70%-ით.

## სადაც ჯერ არ არის ეკრანი

დიალოგები, რომლებიც ზემოთ ცალკე არ არის დახატული (სერიული დამუშავება, OCR, წყლის ნიშანი, კოლონტიტული, პაროლი, შემცირება, ხელმოწერა სერტიფიკატით, შედარება, AI პარამეტრები, ფორმის ველი), იწყობა ამავე ნაწილებით: Dialog-ის ჩარჩო, FormControls (ლეიბლი ზემოთ), Checkbox, Table / ფაილების სია (ScanDialog-ის `et-filelist`), ProgressDialog, Banner — და იმავე ფუტერით (primary ბოლოს).
