# DocumentTabs

გახსნილი ფაილების ჩანართები (QTabWidget, documentMode, movable, closable). სიმაღლე `tab`.

- ზოლის ფონი `surface-200`; აქტიური ჩანართი `surface-100` (ერწყმის ტოლბარს) + ზემოთ 2px `brand` ხაზი, `body-strong`.
- არააქტიური: `ink-muted`; hover — `surface-100`.
- შეუნახავი ცვლილება: 6px წერტილი `brand-text` სახელის შემდეგ (ვარსკვლავი `*` არა).
- გრძელი სახელი იჭრება „…“-ით, max 220px; სრული გზა tooltip-ში.
- დახურვის × ყოველთვის ჩანს (20px სამიზნე).
