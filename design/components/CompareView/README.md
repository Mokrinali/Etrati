# CompareView

„ჩართალა → ორი ფაილის შედარება…“ (`compare_view.py` `CompareView`), ცალკე ჩანართი მთავარ ფანჯარაში. ფაილებს არ ცვლის.

- თავზე Banner (გვერდების რაოდენობა განსხვავდება — warning; შეცდომა — danger).
- ზოლი: დაპატარავება · გადიდება · სიგანეზე · მთელი გვერდი (ToolButton, აიკონი `icons-v2`) | „ხელით გასწორება…“ · „გვერდების წყვილები“ (checkable) · „ავტომატური გასწორება“ (ჩანს მხოლოდ ხელით გასწორების შემდეგ: წერტილებს ხსნის).
- გასწორება: ჯერ ისე, როგორც არის; თუ ნახაზები ერთმანეთს არ ედება — ავტომატურად. ვერ გამოვიდა → warning ბანერი „ნახაზები ავტომატურად ვერ გასწორდა… გაასწორეთ ხელით“ მოქმედებით „ხელით გასწორება…“.
- ხელით: info ბანერი ნაბიჯ-ნაბიჯ („ძველ ნახაზზე დააწკაპუნეთ პირველ წერტილზე…“, ოთხი დაწკაპუნება: ძველი, ახალი, ძველი, ახალი), კურსორი ჯვარი, მითითებული წერტილი — 12pt ჩარჩო `mark-crop`. Esc აუქმებს, სადაც არ უნდა იყოს ფოკუსი.
- მგრძნობელობა: ლეიბლი ზემოთ (`role="muted"`), QSlider 1–5 (ნაგულისხმევი 3), tooltip ხსნის: დაბალი — სკანის ხმაური არ ჩანს. ცვლილებიდან 400მწ-ში თავიდან ადარებს.
- გვერდების წყვილები: Table („ძველი“ | „ახალი“), ნომრები `mono`, „ახალი“ — ComboBox („—“ = არ შედარდეს). ერთ ახალ გვერდს ერთი წყვილი აქვს. გვერდების რაოდენობა თუ განსხვავდება, ცხრილი თავისით ჩანს.
- სამი სვეტი QSplitter-ში: **ძველი** | **ახალი** | ცვლილებები (`sidebar` სიგანე, `surface-200`).
  - პანელის სათაური „ძველი: სახელი“ / „ახალი: სახელი“ — `small` / `ink-muted` (`role="muted"`), სრული გზა tooltip-ში.
  - ჩარჩოები გვერდზე: ძველზე `mark-diff-old` (წაიშალა/შეიცვალა), ახალზე `mark-diff-new` (დაემატა/შეიცვალა); 1.5px, არჩეული ცვლილება 3px.
  - სია: „გვ. N · შეიცვალა: „100“ → „250““ / „გვ. N · დაემატა“; ტექსტისა და ნახაზის ერთი ცვლილება ერთი რიგია. ქვეშ „წინა“ / „შემდეგი“ (ციკლურად).
- ორივე პანელი ერთად მოძრაობს და ერთ ფიზიკურ მასშტაბზეა („ჩართალა → ერთად მოძრაობა“ თიშავს).
- გამოთვლა — ProgressDialog „ნახაზები დარდება: გვერდი 3 / 12“, „გაუქმება“ ყოველთვის; გაუქმების შემდეგ: „შედარება გაუქმდა. ფაილები უცვლელია.“
- ფაილების არჩევა — Dialog 520px: ლეიბლები ველის ზემოთ („ძველი ფაილი (რაც გაგზავნეთ)“, „ახალი ფაილი (რაც დაგიბრუნეს)“), „არჩევა…“ ველის გვერდით; ქვედა რიგში „გაუქმება“ (ghost) და „შედარება“ (primary, ბოლოს; გათიშულია, სანამ ორი განსხვავებული ფაილი არ არის).
