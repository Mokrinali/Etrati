# SignaturePad

„ხელმოწერის სურათი“ (`forms.py` `SignaturePad`). შიგნით QTabWidget → inline segmented (`et-segs is-inline`): **დახატვა · აკრეფა · სურათი**.

- ხატვის არე: `paper`, 1px წყვეტილი `line-strong`, `radius-md`; მელანი `ink-signature` 2.6px, მომრგვალებული ბოლოები.
- აკრეფა: ველი „სახელი და გვარი“, ნიმუში Segoe Script → Sylfaen, `ink-signature`.
- info ბანერი ყოველთვის ჩანს (იურიდიული ძალის შესახებ).
- ფუტერი: მარცხნივ „გასუფთავება“ (ghost), მარჯვნივ „გაუქმება“ + „ჩასმა“ (primary).
