# Dialog

QMessageBox და საკუთარი QDialog-ები. სიგანე 420px (ფორმიანი — 520px), `radius-lg`, `shadow-dialog`.

- სათაური `title` — კითხვა ან ფაქტი („შეუნახავი ცვლილებები“); ტექსტი `body` / `ink-muted`.
- აიკონი 36px წრეში: `warning-soft`/`warning`, `danger-soft`/`danger`, `info-soft`/`info`.
- ქვედა ზოლი `surface-200` + ხაზი `line`; ღილაკები მარჯვნივ, primary ბოლოს.
- შეუქცევადი მოქმედების დიალოგში primary-ს ნაცვლად danger ღილაკი, ტექსტში — რა დაიკარგება.
