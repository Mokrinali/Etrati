# FormControls

ველები დიალოგებში (QLineEdit, QComboBox, QSpinBox). სიმაღლე `control`, `radius-sm`, ფონი `surface-raised`, საზღვარი `line-strong`.

- ლეიბლი ველის ზემოთ, `caption`-ის სტილით (`et-label`), არა მარცხნივ — ქართული ლეიბლები გრძელია.
- ფოკუსი: საზღვარი + 1px `focus`.
- შეცდომა: საზღვარი `danger` და ქვეშ ტექსტი `danger`, რა მოხდა და რა ქნას. მარტო წითელი ჩარჩო არა.
- მინიშნება ქვეშ `small` / `ink-muted`.
- რიცხვები და გვერდის დიაპაზონი — `mono`.
