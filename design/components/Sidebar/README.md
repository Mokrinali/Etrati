# Sidebar

გვერდითი პანელი (F4) — ოთხი განყოფილება: **გვერდები**, **სანიშნეები**, **ძიება**, **კომენტარები**. სიგანე `sidebar` (248px), ფონი `surface-200`, მარჯვენა ხაზი `line`.

- ჩანართების ნაცვლად segmented control: აქტიური — `surface-raised` + 1px `line`.
- მინიატურა: `thumb` სიგანე, `paper` + `shadow-page`; ქვეშ ნომერი `caption`.
- მონიშნული გვერდი: 2px `brand` ჩარჩო 3px დაშორებით და ნომერი `brand` ბეჯში (`on-brand`). რამდენიმე მონიშნული — ყველას ერთნაირად.
- გადათრევისას ჩასმის ხაზი: 3px `brand` (ახლანდელი Highlight-ის ნაცვლად).
- ცარიელი სანიშნეები: „ამ ფაილს სანიშნეები არ აქვს“ — `ink-muted`, ცენტრში.
