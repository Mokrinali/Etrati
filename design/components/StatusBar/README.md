# StatusBar

ფანჯრის ქვედა ზოლი (QStatusBar), სიმაღლე `statusbar`, ფონი `surface-200`, `small` / `ink-muted`.

მარცხნივ — დროებითი შეტყობინებები („გაიგზავნა დასაბეჭდად“, 6–8 წმ) და გვერდი/ზომა; მარჯვნივ — მუდმივი: შენახვის მდგომარეობა (`success` აიკონით), ბმულის მისამართი hover-ზე, მასშტაბი `mono`.
