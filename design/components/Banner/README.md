# Banner

დოკუმენტის თავზე ჩასმული შეტყობინება (ახლა `status.emit` / QMessageBox-ით ნაჩვენები ტექსტების ნაწილისთვის). `radius-md`, ფონი `*-soft`, აიკონი სიგნალის ფერით, ტექსტი `ink`.

- **warning** — ფაილი შეკეთდა, ინტერნეტიდან ჩამოტვირთული.
- **info** — დასკანერებული, დაცული ფაილი; შეიძლება ჰქონდეს ერთი მოქმედება (`brand-text` ბმული).
- **success** — ხელმოწერა ვალიდურია.
- **danger** — ოპერაცია ვერ შესრულდა.

ტექსტი: რა მოხდა + რა იცვლება/არ იცვლება. ბლოკავს მხოლოდ მოდალური დიალოგი, ბანერი — არასდროს.
