# WelcomeScreen

ეკრანი, როცა ფაილი არ არის გახსნილი (`_welcome`). ფონი `surface-100`, გარე ველი `space-7`.

1. ლოგო 56px + სახელი „Etrati“ (`APP_NAME`) `display`-ით + ქვესათაური `ink-muted`.
2. ოთხი მოქმედების ბარათი (გახსნა · PDF სხვა ფაილებისგან · ფოტოს ან სკანის გასუფთავება · გაერთიანება) (`radius-lg`): პირველი — მთავარი, `brand` ფილით; დანარჩენი — `brand-soft`.
3. „ბოლოს გახსნილი“ (`heading`) — სია ბარათში: ფაილის სახელი `body-strong`, გზა `small`/`ink-muted`, მარჯვნივ თარიღი. მაქს. 12 (MAX_RECENT).

მთელ ფანჯარაზე გადმოთრევისას: 2px წყვეტილი `brand` ჩარჩო `space-4` დაშორებით და „ჩააგდეთ გასახსნელად“.
