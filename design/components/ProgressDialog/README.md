# ProgressDialog

გრძელი ოპერაციები (`client.run_task`, QProgressDialog): სკანი, სერიული დამუშავება, OCR, კონვერტაცია, შენახვა.

- **განსაზღვრული** — დიალოგი 360px: სათაური `body-strong` („გვერდები მუშავდება…“), 6px ზოლი (`surface-200` ღარი, `brand` შევსება, `radius-pill`), ქვეშ „გვერდი 7 / 12“ `small`. ღილაკი „გაუქმება“ (secondary) — ყოველთვის.
- **განუსაზღვრელი** — 16px spinner (`line` + `brand` რკალი) + ტექსტი `ink-muted`; ჩანს მხოლოდ 400მწ-ის შემდეგ (`setMinimumDuration(400)`).
- გაუქმების შემდეგ: „ოპერაცია გაუქმდა. ფაილები უცვლელია.“ (სტატუსის ზოლში ან info ბანერად).
