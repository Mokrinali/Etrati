# Menu

მენიუების ზოლის მენიუები და კონტექსტური მენიუ (QMenu). სიგანე ≥280px, `surface-raised`, `radius-md`, `shadow-menu`, 4px შიდა ველი.

- რიგი 30px: აიკონი 16px `ink-muted` (ან ცარიელი 16px ადგილი, რომ ტექსტი სწორდებოდეს), ტექსტი, მარჯვნივ კლავიში `mono` `ink-muted`.
- hover / კლავიატურით მონიშნული: `brand-soft` + `brand-text`.
- გამყოფი: 1px `line`.
- სახიფათო ბრძანება ბოლოშია, `danger` ფერით, ცალკე გამყოფით.
