# AppShell

მთავარი ფანჯარა ერთად: მენიუების ზოლი (30px) → მთავარი ტოლბარი (`toolbar`) → ჩანართები (`tab`) → [გვერდითი პანელი `sidebar` | canvas | AI პანელი 300px] → სტატუსის ზოლი (`statusbar`).

- ზედაპირების იერარქია: `surface-100` (ზოლები) → `surface-200` (ჩაღრმავებული: ჩანართების ზოლი, პანელი, სტატუსი) → `canvas` (გვერდების უკან) → `paper`.
- ერთი ტოლბარი საკმარისია 1280px+ ეკრანზე; ვიწროზე ხელსაწყოები მეორე ზოლად გადადის.
- AI პანელი (Ctrl+Shift+A) მარჯვნივ: მომხმარებლის შეტყობინება `brand-soft`, პასუხი `surface-raised` + `line`, გვერდის მითითება `brand-text` — დაწკაპუნებით გვერდზე გადადის.
- სრულ ეკრანზე (F11) მხოლოდ canvas და მცურავი გვერდის ნომერი.
- ეკრანის გაყოფა („ჩართალა → ეკრანის გაყოფა“): canvas ორ პანელად, QSplitter-ით (1px `line`), გვერდიგვერდ ან ერთმანეთის ქვეშ. ორივე ერთი დოკუმენტია: ზოლის გვერდი და მასშტაბი აქტიური პანელისაა (ბოლოს დაწკაპუნებული ან დახატული). „ერთად მოძრაობა“ (checkable) — scroll, zoom და გვერდი ერთად; გაყოფისას გამორთულია (ერთში მთელი ნახაზი, მეორეში დეტალი). „გაუქმება“ ტოვებს პანელს, რომელშიც მუშაობდით.
