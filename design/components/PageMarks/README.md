# PageMarks

ფერები, რომლებსაც აპი PDF გვერდზე ხატავს (view.py). ორივე თემაში ერთნაირია — ქაღალდი (`paper`) ყოველთვის თეთრია.

| ნიშანი | ტოკენი |
|---|---|
| ძიების შედეგი, მარკერი | `mark-highlight` |
| მიმდინარე შედეგი | `mark-current` |
| ტექსტის მონიშვნა | `mark-selection` |
| რედაქტირებადი ბლოკი | `mark-edit` |
| ფორმის ველი | `mark-field` |
| დასაფარი არე | `mark-redact` ჩარჩო + შავი 27% |
| ჩამოჭრა | `mark-crop` |
| ხელმოწერა | `ink-signature` |
