# AiPanel

AI ასისტენტის პანელი (`ai.py` `AiPanel`), მარჯვნივ, სიგანე `ai-panel` (300px), ფონი `surface-100`, მარცხენა ხაზი `line`.

- თავი: აიკონი `brand-text` + „AI ასისტენტი“ `body-strong`; მარჯვნივ „ახალი“, „პარამეტრები…“ (ghost sm).
- შეტყობინებების ტიპები (ახლანდელი `_say(text, color)`-ის ნაცვლად):
  - **კითხვა** (`#2f7de1` bold-ის ნაცვლად) — ბუშტი მარჯვნივ, `brand-soft`.
  - **პასუხი** — ბუშტი მარცხნივ, `surface-raised` + `line`; გვერდის ბმული „[გვ. N]“ `brand-text` 600, დაწკაპუნებით გვერდზე.
  - **შენიშვნა** (`"gray"`-ის ნაცვლად) — ფონის გარეშე, `small` / `ink-muted`.
  - **შეცდომა** (`#c03030`-ის ნაცვლად) — `danger-soft` ფონი, „შეცდომა.“ `danger`-ით, დანარჩენი `ink`.
- შეყვანა: მრავალხაზიანი ველი (QPlainTextEdit, ≥56px), placeholder „კითხვა დოკუმენტზე“; ქვეშ ხარჯი `caption`, „შეჯამება“ (sm) და „გაგზავნა“ (primary sm; მუშაობისას „შეჩერება“, secondary).
- გაგზავნამდე თანხმობის დიალოგი — Dialog, warning აიკონით.
