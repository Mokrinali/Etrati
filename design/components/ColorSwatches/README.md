# ColorSwatches

ანოტაციის ფერის სწრაფი არჩევა ტოლბარზე (ახლანდელი „ფერი…“ დიალოგის წინ). 22px წრეები, არჩეული — 2px `ink` რგოლი 2px დაშორებით.

ნაკრები: `ink-pen` (ნაგულისხმევი), `mark-highlight`, `mark-edit`, `mark-crop`, `ink-signature`, შავი; ბოლოს „+“ → QColorDialog. ეს ფერები დოკუმენტში იწერება, ამიტომ თემასთან არ იცვლება.
