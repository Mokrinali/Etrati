# Table

QTableWidget დიალოგებში — „ფაილების გაერთიანება“ (`MergeDialog`), ხელმოწერების შემოწმება, ფაილის თვისებები.

- ჩარჩო 1px `line`, `radius-md`, ფონი `surface-raised`; სათაური `caption` სტილით, `surface-200` ფონზე.
- რიგი 32px, გამყოფი `line`; ზოლიანი (alternating) რიგები არა.
- რიცხვი (გვერდები) — `mono` / `ink-muted`; რედაქტირებადი უჯრა — `mono`, placeholder `ink-muted`.
- მონიშნული რიგი — `brand-soft`.
- ქვეშ მოქმედებები: „დამატება…“ (sm), „ამოღება“, „ზემოთ“, „ქვემოთ“ (ghost sm, აიკონით — „▲/▼“ სიმბოლოების ნაცვლად).
