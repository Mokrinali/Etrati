# Button

ტექსტიანი ღილაკი დიალოგებში, პანელებში და მისასალმებელ ეკრანზე (QPushButton).

## ვარიანტები
- **primary** — `brand` ფონი, `on-brand` ტექსტი. ერთ ხედში მაქსიმუმ ერთი: მთავარი მოქმედება („შენახვა“, „გაერთიანება“, „გაგრძელება“).
- **secondary** (ნაგულისხმევი) — `surface-raised` ფონი, `line-strong` საზღვარი.
- **ghost** — უფონო; „გაუქმება“, მესამეული მოქმედება.
- **danger** — `danger` ჩარჩო და ტექსტი, აიკონით. მხოლოდ შეუქცევადისთვის: „მონიშნულის სამუდამოდ წაშლა“, „ფარული მონაცემების წაშლა“.
- ზომები: `sm` (`control-sm`, ძიების წინა/შემდეგი), ნაგულისხმევი (`control`), `lg` (`control-lg`, მისასალმებელი ეკრანი).

## წესები
- ზმნა პირველი, მოკლედ: „შენახვა“, „გახსნა…“. სამი წერტილი (…) = გაიხსნება დიალოგი.
- დიალოგში რიგი მარჯვნივ: ghost → secondary → primary (primary ბოლოს).
- disabled-ზე `ink-disabled` + `surface-200`; tooltip-ში ახსენი, რატომ არის გათიშული.
- ფოკუსი: `focus` 2px რგოლი.
