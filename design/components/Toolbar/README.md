# Toolbar

ორი ზოლი ფანჯრის ზემოთ (`window.py` `_toolbar`), სიმაღლე `toolbar` (44px), ფონი `surface-100`, ქვედა ხაზი `line`, `setMovable(False)`.

1. **მთავარი** (აიკონი `icon-tool` 20px): გვერდითი პანელი · გახსნა · შენახვა · ბეჭდვა | გაუქმება · გამეორება · გვერდების მართვა | წინა/შემდეგი გვერდი · გვერდის ველი (QSpinBox, `mono`, 56px) „/ 24“ | დაპატარავება · მასშტაბი (რედაქტირებადი QComboBox, 84px, `mono`) · გადიდება · სიგანეზე · მთელი გვერდი | ორი გვერდი · მობრუნება · ძიება · AI.
2. **კომენტარი და რედაქტირება** (18px): მონიშვნა · მარკერი · ხაზგასმა · გადახაზვა | შენიშვნა · ტექსტი | ხატვა · ოთხკუთხედი · ელიფსი · ხაზი · ისარი | შტამპი · სურათი | ტექსტის შეცვლა · დასაფარი · ფორმის ველი | ხელმოწერის სურათი · ფერის წრეები (ColorSwatches, „ფერი…“-ის ნაცვლად).

წესები: ჯგუფები `et-sep`-ით; ლეიბლი მხოლოდ tooltip-ში (გამონაკლისი არ არის); checked — `brand-soft` + `brand-text` (გვერდითი პანელი, გვერდების მართვა, ორი გვერდი, AI, არჩეული ხელსაწყო). ზოლის ველები (გვერდი, მასშტაბი) 28px სიმაღლისაა, რომ ღილაკებთან ერთ ხაზზე იჯდეს.
